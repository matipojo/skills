---
name: decision-driven-design
description: Decision Driven Design (DDD). Plan a feature, system or decision through a heated debate between personas, a wide and deep decision tree, and simulated decisions, written as plain "We decided X because Y" sentences.
---

Create a heated debate between different personas to plan [your topic].

Create a heated argument, create decision nodes, create a very wide and very deep decision tree.
Then simulate the constraints or benefits that come up at different nodes of the tree.
Simulate my decisions.
The result is a file of decision sentences in plain language.
For example: We decided to do X because Y.

If the user wants visual illustrations, use the contrast-illustration skill.
